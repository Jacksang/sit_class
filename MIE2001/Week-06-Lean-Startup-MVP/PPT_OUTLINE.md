## Part 2: The Lean Startup (25 min)

### Slide 4 — Build-Measure-Learn Loop
```
[Ideas] → [Build] → [Product] → [Measure] → [Data] → [Learn] → [loop]
```

### Slide 5 — Traditional vs. Lean
| Traditional | Lean |
|-------------|------|
| Build complete product | Build smallest test |
| Launch big | Launch small, early |
| Hope for success | Measure response |
| Pivot if desperate | Pivot based on data |

### Slide 6 — Validated Learning
- Not about building the right product → LEARNING what the right product is
- Each BML cycle teaches you something concrete

### Slide 7 — Pivot or Persevere?
- **Persevere:** Confirms direction. Continue.
- **Pivot:** Direction is wrong. Change course.
- **Kill:** Not viable. Move on.
- Examples: Instagram (Burbn → photos), Slack (Glitch → chat)

## Part 3: What is an MVP? (20 min)

### Slide 8 — MVP is NOT a Prototype
| Prototype | MVP |
|-----------|-----|
| Tests: can we build it? | Tests: will anyone want it? |
| Focus: design & tech | Focus: customer behavior |
| Audience: internal | Audience: real customers |

### Slide 9 — The Minimum in MVP
**Myth:** MVP = smallest possible product
**Truth:** MVP = smallest test of your RISKIEST ASSUMPTION

### Slide 10 — Types of MVPs
| Type | What It Is | Best When |
|------|-----------|-----------|
| Landing page | Signup button + description | Testing interest |
| Concierge | Manually deliver the service | Testing demand |
| Wizard of Oz | Pretend tech works, manual behind scenes | Testing automation |
| Piecemeal | Existing tools simulate product | Testing value prop |
| Video | Demo video (Dropbox-style) | Building anticipation |

### Slide 11 — Concierge Example
- Problem: busy professionals need healthy meals
- MVP: founders personally shop, cook, deliver 5-10 meals/day
- If people reorder → demand exists. If not → fix or pivot.
- **You learn MORE from manual delivery than a built app nobody uses**
