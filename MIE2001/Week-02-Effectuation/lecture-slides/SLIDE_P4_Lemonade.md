## Slide P4-1 — Principle 4: Lemonade Intro

**Text:**
```
🍋  Principle 4: Lemonade

    "Embrace surprises — turn bad news
     into opportunity"

    Tagline: When life gives you lemons...

    The traditional reaction:
    ❌ Surprise = problem = failure
    ❌ "My plan didn't work, so I'm done"

    The effectual reaction:
    ✅ Surprise = data = discovery
    ✅ "That didn't work — what DID I learn?"
```

**Speaker Notes:**
> "Principle four: Lemonade. 'Embrace surprises — turn bad news into opportunity.'
>
> When your plan doesn't work, the instinct is to think you've failed. Expert entrepreneurs reframe surprise as data. As discovery.
>
> The question is: 'That didn't work — what did I just learn?'"

**Image Prompt:** Simple lemon with a splash turning into a glass of lemonade. Minimalist line art. Yellow accent.

## Slide P4-2 — The Psychology of Surprise

**Text:**
```
🍋  Why Surprises Are Valuable

    ┌──────────────────────────────────────────────────┐
    │ A predictable outcome = you learned nothing new  │
    │                                                  │
    │ An unexpected outcome = you just discovered      │
    │ something the predictable plan would never       │
    │ have shown you                                   │
    │                                                  │
    │ ┌──────────────────────────────────────────┐     │
    │ │ Surprises are not problems to avoid.     │     │
    │ │ They are opportunities to discover.      │     │
    │ └──────────────────────────────────────────┘     │
    │                                                  │
    │ Key mindset shift:                               │
    │ "I was wrong" → "I now know something            │
    │   I didn't know before. That's progress."        │
    └──────────────────────────────────────────────────┘
```

**Speaker Notes:**
> "Think about it: if your plan went exactly as predicted — you learned nothing new. You just confirmed what you already knew.
>
> An unexpected outcome? That's pure discovery. The predictable plan would never have shown you that.
>
> When you shift from 'I was wrong' to 'I now know something I didn't know before' — that's when you can make lemonade."

## Slide P4-3 — Lemonade Examples

**Text:**
```
🍋  Lemonade in Action

    ┌──────────────────────────────────────────┐
    │ 📌 Post-it Notes (3M)                     │
    │   Failed attempt: super-strong glue      │
    │   Discovery: weak, reusable adhesive     │
    │   Lemonade: Post-it Notes → $1B+ product │
    │                                          │
    │ 📌 Slack                                  │
    │   Failed: video game "Glitch"            │
    │   Discovery: team built internal chat    │
    │   Lemonade: Slack → $27B exit to Salesf. │
    │                                          │
    │ 📌 COVID Singapore F&B                    │
    │   Crisis: dine-in banned                 │
    │   Pivot: delivery                        │
    │   Lemonade: some made MORE profit        │
    └──────────────────────────────────────────┘

    💡 The outcome didn't change.
       Your INTERPRETATION of it did.
```

**Speaker Notes:**
> "Post-it Notes: 3M was trying to create a super-strong glue. They failed. What they got was a weak, reusable adhesive. That 'failure' became a billion-dollar product.
>
> Slack: A failed video game called Glitch. The team built an internal chat tool while the game crashed. That chat tool became Slack — acquired for $27 billion.
>
> COVID in Singapore: dine-in was banned overnight. F&B owners who saw it as a death sentence struggled. Those who said 'how do I do delivery better than before?' — some ended up more profitable.
>
> Same event. Different interpretation. The outcome didn't change — your mindset did."

## Slide P4-5 — From "Problem" to "Experiment"

**Text:**
```
🍋  From "Problem" to "Experiment"

    ┌────────────────────────────────────────────┐
    │ ❌ "My launch failed — I'm a failure"       │
    │                                            │
    │ ✅ "My launch didn't work — now I know     │
    │    what doesn't work. That's progress."    │
    │                                            │
    │ ❌ "Nobody signed up — the idea is dead"   │
    │                                            │
    │ ✅ "Nobody signed up — let me test         │
    │    a different value proposition          │
    │    before giving up"                      │
    └────────────────────────────────────────────┘

    💡 The Lemonade Principle turns:
       "I failed" → "I learned"
       "That's a problem" → "That's data"
       "I should stop" → "Let me try differently"
```
