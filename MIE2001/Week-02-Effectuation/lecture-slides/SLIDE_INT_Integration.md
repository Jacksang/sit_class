## Slide INT-2 — How the 5 Principles Connect

**Text:**
```
🔗  How the 5 Principles Work Together

    ┌─────────────────────────────────────────────────────┐
    │ 🐦 Bird-in-Hand: Look at what you have               │
    │                        │                             │
    │                        ▼                             │
    │ 💰 Affordable Loss: What can you safely risk?        │
    │                        │                             │
    │                        ▼                             │
    │ 🧩 Crazy Quilt: Who can help you fill the gaps?     │
    │                        │                             │
    │                        ▼                             │
    │ 🍋 Lemonade: Something went wrong? Good — learn.    │
    │                        │                             │
    │                        ▼                             │
    │ ✈️ Pilot-in-the-Plane: What can I control NEXT?     │
    │                        │                             │
    │                        ▼                             │
    │                     REPEAT                           │
    └─────────────────────────────────────────────────────┘

    💡 It's a cycle, not a checklist.
       Entrepreneurs run through this loop constantly.
```

**Speaker Notes:**
> "Here's how the five principles work together.
>
> Start with Bird-in-Hand: what do you have? Then apply Affordable Loss: what can you safely risk? Then Crazy Quilt: who can help fill the gaps?
>
> When something goes wrong — and it will — use Lemonade: what did I just learn? Then Pilot-in-the-Plane: what can I control and do next?
>
> Then repeat the loop. That's how expert entrepreneurs think. Not as a checklist, but as a cycle they run through constantly."

**Image Prompt:** A circular flow diagram with 5 icons arranged in a cycle. Arrows connecting each step. Minimalist line art.
