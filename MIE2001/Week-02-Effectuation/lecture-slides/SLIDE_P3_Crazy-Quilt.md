## Slide P3-1 — Principle 3: Crazy Quilt Intro

**Text:**
```
🧩  Principle 3: Crazy Quilt

    "Build partnerships before you compete
     — even with strangers"

    Tagline: Who can HELP me?
             (Not: who can I beat?)

    The traditional approach:
    ❌ "I need to own everything myself"
    ❌ "Partnerships are for later, after I prove myself"

    The effectual approach:
    ✅ "Who already has what I need?"
    ✅ "How can we create value TOGETHER?"
```

**Speaker Notes:**
> "Principle three: Crazy Quilt.
>
> The traditional entrepreneur thinks: 'I need to own everything. I build my own factory, my own logistics, my own software.'
>
> Expert entrepreneurs think differently. They look for partners who already have what they need — even if those partners seem like competitors at first.
>
> The question shifts from 'who can I beat?' to 'who can help me?'"

**Image Prompt:** Simple puzzle pieces fitting together. Two hands reaching toward each other. Minimalist line art.

## Slide P3-2 — Why Crazy Quilt Works

**Text:**
```
🧩  Why Crazy Quilt?

    ┌──────────────────────────────────────────────────┐
    │ 1. Speed: Partners bring existing resources      │
    │    → Skip the building phase, go straight to     │
    │      value creation                              │
    │                                                  │
    │ 2. Shared risk: You don't carry everything       │
    │    → Each partner invests a bit                  │
    │    → Everyone's affordable loss stays small      │
    │                                                  │
    │ 3. Access: Partners open doors you can't         │
    │    → Distribution, trust, credibility            │
    │                                                  │
    │ 4. Serendipity: The best partners often          │
    │    appear when you're NOT looking                 │
    └──────────────────────────────────────────────────┘
```

**Speaker Notes:**
> "Why does Crazy Quilt matter? Four reasons.
>
> Speed — partners bring existing resources. You skip the building phase and go straight to value creation.
>
> Shared risk — each partner invests a bit. Everyone's affordable loss stays small.
>
> Access — partners open doors you can't. Distribution, trust, credibility.
>
> And serendipity — the best partnerships often appear when you're not looking. But you have to be open to them."

## Slide P3-3 — Crazy Quilt Examples

**Text:**
```
🧩  Crazy Quilt in Action

    ┌──────────────────────────────────────────┐
    │ 🇸🇬 Shopee:                                │
    │   Instead of building their own          │
    │   delivery fleet in every country,       │
    │   they partnered with local logistics    │
    │   companies. → Launch in months, not yrs │
    │                                          │
    │ 🇸🇬 Carousell:                             │
    │   Partnered with Singtel for user        │
    │   acquisition. → Millions of users       │
    │   without spending on ads                │
    │                                          │
    │ 🌍 Stripe:                                │
    │   Partnered with Shopify, WooCommerce    │
    │   → Built-in distribution to millions    │
    │   of merchants                           │
    └──────────────────────────────────────────┘

    💡 "Who already has what I want?"
```

**Speaker Notes:**
> "Shopee: Instead of building their own delivery fleet in every SEA country — which would take years and billions — they partnered with local logistics companies. Launch in months, not years.
>
> Carousell: Partnered with Singtel for user acquisition. Millions of users without spending a dollar on ads.
>
> Stripe: Didn't go door-to-door selling payment processing. They partnered with Shopify and WooCommerce — and instantly reached millions of merchants.
>
> The question is always: 'Who already has what I want?'"

## Slide P3-5 — Making the Ask

**Text:**
```
🧩  Making the Ask

    You have their names. Now what?

    ┌────────────────────────────────────────────┐
    │ 1. What VALUE can you offer THEM?          │
    │    (Partnership is two-way)                │
    │                                            │
    │ 2. What's the SMALLEST ask you can make?   │
    │    (Low barrier = higher success)          │
    │    → "Can I get 15 minutes of your time?"  │
    │    → "Would you review one idea?"          │
    │                                            │
    │ 3. How do you follow up?                   │
    │    → 48 hours after meeting, send a note   │
    │    → Reference something they said         │
    └────────────────────────────────────────────┘

    🔑 Partnerships start with small requests,
       not big commitments.
```
